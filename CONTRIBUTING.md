# Contributing to Endospore

This repository is a per-release snapshot, not where Endospore is developed. Nowhere is developed in a private
repository, which is the source of truth, and each Endospore release publishes the edition's public source here
as one new commit.

## Pull requests

Pull requests opened here are not merged into the source of truth, and each release's snapshot replaces the
whole tree, so a change made only here does not survive the next release. There is no contributor license
agreement (CLA) and no Developer Certificate of Origin (DCO) sign-off yet.

## Reporting a problem

Use the support page at [nowhere.mobile/support](https://nowhere.mobile/support). On the phone, Profile → Report
an issue sends a scrubbed report. Never put a profile name or a passphrase in a report, an issue or an email.
